Privacy Policy - PTD Signal Dispatcher

Effective November 14, 2026.

The PTD Signal Dispatcher ("the application") is operated by PaperTrailDebunks studio ("the operator"). Contact: papertraildebunks@gmail.com.

Who uses the application

The application is used by the operator alone, with the operator's own Google account and the operator's own studio mailbox. No other person uses the application, and it is not offered to the public.

What the application accesses

With the mailbox owner's consent, the application reads email in the operator's studio mailbox using Google's read-only Gmail scope (https://www.googleapis.com/auth/gmail.readonly). Read access is used to route production signals between the studio's own departments. The application cannot send, modify, move, or delete email.

How data is handled

Email data is processed in the operator's own Google Cloud project. The OAuth refresh token issued by the consent is stored in Google Cloud Secret Manager in the operator's project. No email data or credential is sold, shared, rented, or disclosed to any third party. The application carries no advertising and no third-party analytics.

Revocation and deletion

The owner may revoke the application's access at any time through the Google account's third-party access settings. On revocation, the stored credential is destroyed. Requests about this policy can be sent to the contact address above.
